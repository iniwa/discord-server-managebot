リアクションで既読確認

案内メッセージへのリアクションを、ロールとは独立して集計します。

集計するメッセージを登録

Discordに「読んだら何かリアクションを付けてください」などの案内を投稿し、そのメッセージのリンクをコピーしてください。

メッセージの右クリックメニューから「メッセージリンクをコピー」で取得できます。
どの絵文字でもOKの場合、1つでもリアクションがあれば反応済みになります。
絵文字を1つ入力します。サーバー絵文字は候補から選べます。

集計のルール

現在サーバーに参加している人を対象に、押した人・押していない人を表示します。Botは除外します。「どの絵文字でもOK」では、複数付けても1人として数え、すべて外すと未反応に戻ります。

日時はBotがリアクション追加を受信した時刻です。登録前やBot停止中のリアクションは、日時不明でも押した人に含めます。日時は別途保存します。

「指定した絵文字のみ」では登録時にBotがその絵文字を付けます。「どの絵文字でもOK」ではBotから絵文字を追加しません。ロールの付与やDM送信はありません。

新しい投稿を作成

本文と投稿先を共通にして、ロールごとのボタンをまとめて投稿します。

Discordの選択肢を読み込んでいます…
1. 投稿先とメッセージ
空欄なら標準の案内文を使います。@everyoneなどを書いても通知は送りません。

2. ロールごとのボタン

1つの投稿に最大25個まで設置できます。並び順に5個ずつ表示します。

保存すると新しい投稿を作成します。以前のボタンは無効になります。
